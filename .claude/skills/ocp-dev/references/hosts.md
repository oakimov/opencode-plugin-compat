# Host paths

Resolve overrides first: `OPENCODE_CONFIG_DIR`, `MIMOCODE_HOME`, `KILO_CONFIG_DIR`, `PI_CODING_AGENT_DIR`, `PI_BRIDGE_CONFIG`, `XDG_CONFIG_HOME`, `XDG_CACHE_HOME`, `OCP_DEV_STATE_DIR`.

## Clone family (`ocp setup` + wrapper)

| Host | CLI fallback | Config dir | Config candidates (first existing wins) | Packages cache |
|---|---|---|---|---|
| `opencode` | `~/.opencode/bin/opencode` | `~/.config/opencode` | `opencode.json`, `opencode.jsonc` | `~/.cache/opencode/packages` |
| `mimo` | `~/.mimocode/bin/mimo` | `~/.config/mimocode` or `$MIMOCODE_HOME/config` | `mimocode.json`, `mimocode.jsonc` | `~/.cache/mimocode/packages` or `$MIMOCODE_HOME/cache/packages` |
| `kilo` | `~/.local/bin/kilo` | `~/.config/kilo` | `kilo.jsonc`, `kilo.json`, `opencode.json`, `opencode.jsonc`, `config.json` | `~/.cache/kilo/packages` |

Local wrapper: `${OCP_DEV_STATE_DIR:-~/.cache/ocp-dev}/<host>/provider/`
Manifest: `${OCP_DEV_STATE_DIR:-~/.cache/ocp-dev}/<host>/state.json`

Clone local slot:

- `plugin` += `<wrapper>/dist/index.js`
- `provider.cursor.npm` = `file://<wrapper>/dist/index.js`

Clone npm slot:

- `plugin` += `cursor-opencode-provider@latest`
- `provider.cursor.npm` = `cursor-opencode-provider`

Doctor: `bun packages/ocp/bin/ocp.ts doctor --host <opencode|mimo|kilo>`

## Pi family (`pi-bridge`, never `ocp setup`)

| Host | CLI fallback | Config |
|---|---|---|
| `pi` | `/opt/local/bin/pi` | `~/.pi/agent/pi-bridge.json` |
| `omp` | `~/.bun/bin/omp` | `~/.omp/agent/pi-bridge.json` |

Or `$PI_BRIDGE_CONFIG`, or `$PI_CODING_AGENT_DIR/pi-bridge.json`.

Local: `providers[].package` is the provider checkout `dist/index.js`.
Npm: `providers[].package` is `cursor-opencode-provider`.
Other provider entries and extra fields on the Cursor entry must survive.

Bridge checkout: `packages/pi-bridge`. Host `pi-ai` may be symlinked under `packages/pi-bridge/node_modules/` — only remove that symlink if it is a symlink.

## DSH family (`dsh-bridge`, never `ocp setup`)

| Host | CLI | Config |
|---|---|---|
| `dsh` | `pnpm --prefix <deepseek-harness> dsh` | `$DSH_HOME/profiles/web/cordis.patch.yml` or `~/.dsh/profiles/web/cordis.patch.yml` |

Local: `dsh plugin --profile web add file:<packages/dsh-bridge>` and patch `providers[].package` is the provider checkout `dist/index.js`.
Npm: `@opencode-compat/dsh-bridge` plus `providers[].package: cursor-opencode-provider`.

Bridge checkout: `packages/dsh-bridge`. Do not edit the DSH host tree.

## Stock provider

Default: `$OCP_DEV_PROVIDER_PATH`, else `../cursor-opencode-provider`, else `~/Projects/cursor-opencode-provider`.

Clean: `dist/index.js` exists, no `generated by ocp setup`, `@opencode-ai/plugin` is a real directory.

Dirty: in-place shim or facade symlink. Fix with `./scripts/ocp-dev.sh unshim`, not by editing the checkout.
