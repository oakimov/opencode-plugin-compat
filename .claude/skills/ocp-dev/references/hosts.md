# Host paths

Resolve overrides first: `OPENCODE_CONFIG_DIR`, `MIMOCODE_HOME`, `KILO_CONFIG_DIR`, `PI_CODING_AGENT_DIR`, `PI_BRIDGE_CONFIG`, `XDG_CONFIG_HOME`, `XDG_CACHE_HOME`, `OCP_DEV_STATE_DIR`, `DSH_HOME`, `DSH_HARNESS_ROOT`.

## Native OpenCode (not an ocp-dev shim host)

OpenCode loads consumer plugins through its own plugin surface. Point it at the provider checkout `dist/` (or a published package). Do not `run`/`shim` OpenCode and do not write `~/.cache/ocp-dev/opencode` into its config.

## Clone family (`ocp setup` + wrapper)

Shim hosts only. OpenCode is listed nowhere below because it is native.

| Host | CLI fallback | Config dir | Config candidates (first existing wins) | Packages cache |
|---|---|---|---|---|
| `mimo` | `~/.mimocode/bin/mimo` | `~/.config/mimocode` or `$MIMOCODE_HOME/config` | `mimocode.json`, `mimocode.jsonc` | `~/.cache/mimocode/packages` or `$MIMOCODE_HOME/cache/packages` |
| `kilo` | `~/.local/bin/kilo` | `~/.config/kilo` | `kilo.jsonc`, `kilo.json`, `opencode.json`, `opencode.jsonc`, `config.json` | `~/.cache/kilo/packages` |

Local wrapper: `${OCP_DEV_STATE_DIR:-~/.cache/ocp-dev}/<host>/provider/`
Manifest: `${OCP_DEV_STATE_DIR:-~/.cache/ocp-dev}/<host>/state.json`

Clone local slot:

- `plugin` += `<wrapper>/dist/index.js`
- `provider.cursor.npm` = `file://<wrapper>/dist/index.js`

Clone npm slot:

- `plugin` += `cursor-opencode-provider@latest`
- `provider.cursor.npm` = `cursor-opencode-provider`

Doctor: `bun packages/ocp/bin/ocp.ts doctor --host <mimo|kilo>`

## Pi family (`pi-bridge`, never `ocp setup`)

| Host | CLI fallback | Config |
|---|---|---|
| `pi` | `/opt/local/bin/pi` | `~/.pi/agent/pi-bridge.json` |
| `omp` | `~/.bun/bin/omp` | `~/.omp/agent/pi-bridge.json` |

Or `$PI_BRIDGE_CONFIG`, or `$PI_CODING_AGENT_DIR/pi-bridge.json`.

Local: `providers[].package` is the provider checkout `dist/index.js`.
Npm: `providers[].package` is `cursor-opencode-provider`.
Other provider entries and extra fields on the Cursor entry must survive.

Bridge checkout: `packages/pi-bridge`. Host `pi-ai` may be symlinked under `packages/pi-bridge/node_modules/` — only remove that symlink if it is a symlink.

## DSH family (`dsh-bridge`, never `ocp setup`)

| Host | CLI | Config |
|---|---|---|
| `dsh` | `$DSH_HARNESS_ROOT` or OCP sibling `../deepseek-harness`, then `node <harness>/apps/cli/lib/bin.js` (built CLI; not checkout `pnpm dsh` / tsx). CLI fallback `~/.local/bin/dsh` | `$DSH_HOME/profiles/web/cordis.patch.yml` or `~/.dsh/profiles/web/cordis.patch.yml` |

Local: `pnpm install` plus the harness documented build (`build:native-system`, host/client lib, `build:web`; tsdown only for directories with `package.json`), then `dsh plugin --profile web add file:<packages/dsh-bridge>` and patch `providers[].package` is each provider checkout `dist/index.js` (Cursor plus Devin when `../devin-opencode-provider` or `$OCP_DEV_DEVIN_PROVIDER_PATH` exists). Launch the built CLI (`node <harness>/apps/cli/lib/bin.js web`), not checkout `pnpm dsh web`.
Npm: `@opencode-compat/dsh-bridge` plus `providers[]` rows for `cursor-opencode-provider` and `devin-opencode-provider`.

Bridge checkout: `packages/dsh-bridge`. Do not edit DSH host source; `run` may write gitignored `lib/` / `dist/` via the harness's own build scripts.

## Stock provider

Default: `$OCP_DEV_PROVIDER_PATH`, otherwise `../cursor-opencode-provider`.

Clean: `dist/index.js` exists, no `generated by ocp setup`, `@opencode-ai/plugin` is a real directory.

Dirty: in-place shim or facade symlink. Fix with `./scripts/ocp-dev.sh unshim`, not by editing the checkout.
